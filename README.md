# Cars Marketplace

## Overview

This project is a web application built using modern web development tools and methodologies to ensure maintainability, scalability, and performance.

---

## Technologies Used

### React.js

[React.js](https://react.dev/) is a JavaScript library for building user interfaces. It allows us to create reusable UI components and manage application state efficiently. Its declarative nature helps in writing predictable and maintainable code.

### Webpack

[Webpack](https://webpack.js.org/) is a powerful module bundler used to compile JavaScript, TypeScript, CSS, and other assets. It optimizes the build process by minimizing the bundle size and ensuring faster load times.

### CSS Modules

[CSS Modules](https://github.com/css-modules/css-modules) provide locally scoped styling, preventing global namespace conflicts. This ensures that styles are applied only to specific components, improving maintainability.

### TypeScript

[TypeScript](https://www.typescriptlang.org/) is a statically typed superset of JavaScript that enhances code reliability by catching errors during development. It provides autocompletion, better code documentation, and improved developer experience.

### FSD Architecture

[Feature-Sliced Design (FSD)](https://feature-sliced.design/) is an architectural approach for organizing the project. It divides the application into layers such as:

- `app/` – application-level configurations
- `pages/` – page components
- `features/` – feature-specific modules
- `entities/` – business entities
- `shared/` – shared utilities and components

This structure promotes scalability, reusability, and better project maintainability.

### React Hook Form

[React Hook Form](https://react-hook-form.com/) is used for form state management and validation. It improves performance by reducing unnecessary re-renders and eliminates the need for excessive boilerplate code.
